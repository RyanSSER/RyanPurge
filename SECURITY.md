# Security Policy

## Scope

Security reports for the official RyanPurge repository, website, package, and source code are welcome. Please do not publicly disclose credentials, account tokens, private message contents, or an exploitable vulnerability before it has been reviewed.

## Reporting a vulnerability

Contact **RyanOS privately through the official Discord community at RyanOS on GitHub**. Include a short description, affected release, device or host-app context, reproduction steps, and the security impact. Redact all personal data and never send account tokens or passwords.

If GitHub private vulnerability reporting is enabled for this repository, it may also be used for a confidential report. Public issues are appropriate for ordinary bugs and feature requests, not undisclosed security vulnerabilities.

## Supported release

The current official release is **RyanPurge 1.0.0**. Security fixes, when needed, are published only through the official RyanPurge repository and the official installation source.

## Responsible disclosure

Please allow reasonable time for validation and remediation before publishing technical details. Unofficial modified builds are outside the support scope of RyanOS.
