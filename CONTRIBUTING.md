# Contributing to RyanPurge

RyanPurge is maintained and released by **RyanOS**. Suggestions, bug reports, and feature ideas are welcome when they are clear, respectful, and focused on improving safety, reliability, accessibility, or usability.

## Where to send an idea

For general suggestions and improvement proposals, contact RyanOS through the official Discord community at **RyanOS on GitHub**. For reproducible bugs or technical issues, a GitHub issue may be opened with the relevant device, host-app version, plugin version, steps to reproduce, expected result, and actual result.

## Before submitting

Please check the README and existing issues first. Do not include account tokens, passwords, private message contents, personal identifiers, or other sensitive information in a public issue. Redact screenshots and logs before sharing them.

## Pull requests and redistribution

The repository accepts discussion and feedback, but the proprietary terms in `LICENSE.md` remain in force. Do not submit a pull request that copies code from an unofficial build, changes the project identity, removes attribution, introduces account-token handling, bypasses host-app safeguards, or turns RyanPurge into a redistributed or rebranded package.

A suggestion or pull request does not guarantee inclusion in an official release. Only RyanOS can approve, package, name, and publish official RyanPurge releases.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md) and the project’s proprietary terms.
